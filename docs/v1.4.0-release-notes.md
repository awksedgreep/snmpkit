# SnmpKit v1.4.0 Release Notes

**Release Date:** September 2026
**Version:** 1.4.0
**Previous Version:** 1.3.24

## Overview

This minor release collects the safe half of a full codebase review
(24 findings, filed as issues #4–#27). Everything shipping here is
backward compatible: no public modules, functions, arities, option names,
or documented return shapes were removed or changed. The remaining
findings need either a working interop harness or a major-release
decision and are tracked openly on GitHub.

## Highlights

### Correctness fixes (behavior now matches the docs/RFCs)

- X.690 first-arc OID handling corrected in all three implementations
  (`ASN1`, PDU fast encoder/decoder): second arc unbounded under arc 2,
  multibyte first sub-identifier parsed before splitting (#4).
- Engine guarantees exactly-once replies and cancels timeout timers on
  completion; no more double replies or orphaned timers (#10).
- Pooled Engine connections drain back to `:idle` with error accounting
  instead of saturating permanently; sockets close on stop/terminate (#11).
- MultiV2 batch backstop fails only expired requests; V2Walk single-target
  path no longer duplicates PDUs on stray messages (#16).
- Sim walk responder returns `endOfMibView` for v2c / `noSuchName` for v1
  at end of MIB, matching the adjacent branches and the RFCs (#21).
- USM security-parameters decoding is real ASN.1 instead of mocked
  boots/time, sharing one key vocabulary with the V3 encoder (#9, part).

### Robustness (new bounds, all tunable, all counted)

- Sim UDP server caps datagram size (65,535) and concurrent packet tasks
  (1,000) with `packets_dropped_oversize` / `packets_dropped_overload`
  counters (#17).
- Compiled-MIB loading uses `binary_to_term([:safe])` with a 10 MB cap
  and actionable errors (#19).
- Router isolates route failures per caller and never interns atoms from
  engine names (#12).
- `auto_start_services: false` with missing services fails fast naming
  them, instead of a downstream noproc exit (#13, part).

### New APIs (additive only)

- `SnmpKit.SnmpMgr.CircuitBreaker.allow_request/2`: admission check to
  pair with the existing `record_success/2` / `record_failure/3`. `call/4`
  is reimplemented on top of it and keeps its exact return contract (#14).
- `SnmpKit.SnmpSim.Core.Server` accepts `:max_in_flight` and
  `:max_packet_size` options (#17).
- `SocketManager` health uses absolute backlog thresholds and counts
  engine-missing drops (#15, part).

### Hygiene (no behavior change)

- Debug `IO.inspect`/`IO.puts` removed from library and test code; an
  AST-based CI gate enforces the rule for `lib/` and `test/` (#24, #26).
- Walk/Bulk docs show enriched maps with verified examples (#25).
- `walk_*` suites consolidated under `test/snmp_mgr/`; the never-running
  debug file renamed (still `:manual`-excluded); `lsof`/`kill -9` helper
  replaced with a portable warn-only port probe (#26).
- HexDocs module groups fixed to real module names with full coverage
  (#27, part).
- SharedProfiles caches the sorted OID index (identical results, no more
  copy-and-sort per GETNEXT) (#23).

## API Compatibility

This release is backward compatible:

- No public modules, functions, arities, or option names were removed.
- No documented return shapes were changed.
- Fixes that alter observable values (#4 decode outputs, #21 v2c
  end-of-walk varbind) correct them toward RFC/real-device behavior; the
  in-library manager accepts both shapes.
- `CircuitBreaker.call/4` keeps its signature, returns, transitions, and
  metric counters; execution just moves to the caller.

## Deferred to a major-release decision

Issues #5, #6, #7, #8, #18, #20, #22, #27 (removals), the #9
verify/decrypt wiring, #13 single-tree supervision, and #15 socket
ownership. Each carries a contract-caution note on its issue explaining
exactly what would break and what the migration looks like.

## Validation

- Every change reviewed diff-by-diff; round-trip and caller audits done
  by reading (no local Elixir toolchain in the review environment).
- Full `mix test`, `mix format --check-formatted`, and the new CI gate
  run on push; do not publish to Hex if CI is red.
